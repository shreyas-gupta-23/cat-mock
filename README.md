# CAT 2026 — IIM A prep

General category. Graduation **84% final**. Working target **99.7 / rank ~800**. Details in [PROFILE.md](PROFILE.md).

## Launch the exam room

From this folder, double-click `Start-Exam.cmd`, or:

```bat
cd app
npm install
npm start
```

Then open **http://127.0.0.1:5173**. Theory notes are at **http://127.0.0.1:5173/theory/**.

`npm install` is only needed the first time. Leave the command window open while you sit a paper. Stop the room with Ctrl+C.

## What you can sit

29 full keyed papers. MCQ is +3 / −1. TITA is +3 / 0. A blank scores 0. A marked question with an answer still counts. Each section locks at 40 minutes.

| Papers | Length |
| --- | --- |
| CAT 2017, 2018, 2019 — Slot 1 and Slot 2 | 100 (34 / 32 / 34) |
| CAT 2020 — Slot 1, 2, 3 | 76 (26 / 24 / 26) |
| CAT 2021, 2022, 2023 — Slots 1–3 | 66 (24 / 20 / 22) |
| CAT 2024, 2025 — Slots 1–3 | 68 (24 / 22 / 22) |
| Career Launcher Free Mock 1 and 2 | 68 |
| Cracku Free Mock 1, 2, and 3 | 68 |

Take **CAT 2024 Slot 1** or **CAT 2025 Slot 1** as the first diagnostic. After submit, use **Download review** and paste that markdown here.

The on-screen percentile is a CAT 2025 raw-score ballpark for a 68-question paper. It is not All-India rank, and it is the wrong scale for the 76-question and 100-question papers.

Career Launcher Free Mock 2’s RC questions do not include the passage text. The capture saved the questions and the official option keys, not the four passages. Career Launcher Free Mock 1 does include its passages.

Cracku Free Mock 1 and 2 are complete. The 14 questions that were missing from the first capture are filled from the live review. Keys were already on file and were not changed.
