Scan, abandon, arrangement, binary logic.

01

Sheet

CAT DILR is set selection, not “attempt all.” Forty minutes, five sets (recent pattern). Target for 99.7: two clean sets plus maybe a leftover TITA — about 8–10 correct, not heroics.

Minute 0–3. Read the first 5–6 lines of every set. Rank: familiar skeleton, small integers, TITA that looks countable. Skip: nested “if A then unless B except C”, undefined figures, Q1 that already looks like an 8-minute grind.

Abandon rule. 12 minutes and one answer \(\Rightarrow\) leave. Sunk cost is how DILR percentiles die.

Arrangements. Slots as columns. Place the most constrained person first. Circular: fix one person to kill rotational symmetry. Linear with neighbours: glue. “Not adjacent” = total − adjacent.

Binary / games of truth. Two types (always-truth / always-lie, or two colours). Assume one statement, chase contradictions. Invariants: number of liars, parity.

Quant based LR. Treat the paragraph as constraints on a table you drew. Don’t start arithmetic before the grid exists.

Trap. Opening the “interesting” set first. Interesting is not easy. Also: finishing a doomed set because you already spent 8 minutes.
Move. After every mock, tag sets should-have-picked / correctly-skipped / should-have-skipped. That log is the syllabus.
